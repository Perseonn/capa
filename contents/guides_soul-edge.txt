Welcome to Soul Edge / Soulblade weapon stats guide! This guide will cover all of Soul Edge / Soul Blade weapons' parameter. SE uses a 'block' parameter to tell you how strong the weapon is, but not even a single weapon with same block count will be exactly the same between characters. This guide will tell you all statistics except the weight and special effects (which is unable to be determined via memory monitoring).

This guide was previously published on Another Stage of History.

+ Legend

++ Refined Data
* **Power:** In-game Power = ( POW * 6.25 + B )%
* **Defense:** In-game Defense = ( 1 / ( DEF * 6.25 + P ) )%
* **Strength:** In-game Strength= ( STR * 6.25 )%
* **Durable:** In-game Durability = ( 1 / ( DUR * 6.25 ) )%
* **Range:** In-game Range = ( RNG * 6.25 ) / 100

++ Raw Data
* **POW:** System Power
* **DEF:** System Defense.
* **STR:** System Strength
* **DUR:** System Durability
* **RNG:** System Range
* **RP:** Raw Power
* **RD:** Raw Defense
* **B:** Bonus power = RP / 13 * 0.3
* **P:** Penalty defense = RD / 13 * 0.3

+++ Notes
* Higher raw defense and durability, means less defense and durability the weapon has. For example, if a weapon has 20 raw defense, the weapon has 120% defense multiplier, meaning you simply take 20% more damage. This behavior is consistent, going all the way at least Soulcalibur III. The refined data shows you the inverse of this number, rendering 120% as 80% ( 1.2 ^ -1) to visually show that it has less defense, and match what the game shows: lower bar count means lower defense.
* Formula for B and P are speculated using average of RP or RD increase vs B or P increase per character.
* Weight was not found.

++ Addressing Guests
Guests includes Han Myong (Han-Myeong), Bangu (Bangoo), Diver, Monkasei, Chie, Sophitia!, Hage-Sieg, Nugi Taki, Sophitia!!, Belti (Vercii), and Mabochie. They have different weapon models but all have the same stats as Cervantes. The following is the moveset for each of them:
* **Siegfried! / Hage-Sieg**: Siegfried's moveset and weapon model
* **Han Myong:** Hwang's expanded moveset and weapon model
* **Bangu:** Seong Mi-na's moveset and weapon model
* **Diver:** Sophitia's moveset
* **Monkasei:** Mitsurugi's moveset (what a traitor!)
* **Chie / Mabochie:** Seong Mi-na's moveset
* **Sophitia! / Sophitia!!:** Sophitia's moveset and weapon model
* **Teppou Hei:** Mitsurugi's moveset with the Tanegashima (that's one way to use a rifle)
* **Nugi Taki:** Taki's moveset and weapon model
* **Belti:** Cervantes's moveset

Siegfried!'s and Teppou Hei's weapon #1 to #7 often crashes the game and if they work, they only mimic the shape of last weapon you select without the texture.
