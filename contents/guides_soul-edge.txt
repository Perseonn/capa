Welcome to Soul Edge weapon stats guide! This guide will cover all of Soul Edge / Soul Blade weapons' parameter. SE uses a 'block' parameter to tell you how strong the weapon is, but not even a single weapon with same block count will be exactly the same between characters. This guide will tell you all statistics except the weight and special effects (which is unable to be determined via memory monitoring).

This guide was previously published on Another Stage of History.

+ Legend
++ Raw Data
* **POW:** System Power
* **DEF:** System Defense
* **STR:** System Strength
* **DUR:** System Durability
* **RNG:** System Range
* **RP:** Raw Power
* **RD:** Raw Defense
* **B:** Bonus power = RP / 13 * 0.3
* **P:** Penalty defense = RD / 13 * 0.3

++ Refined Data
* **Power:** In-game Power = ( POW * 6.25 + B )%
* **Defense:** In-game Defense = ( 200 - ( DEF * 6.25 + P ) )%
* **Strength:** In-game Strength= ( STR * 6.25 )%
* **Durable:** In-game Durability = ( 200 - ( DUR * 6.25 ) )%
* **Range:** In-game Range = ( RNG * 6.25 ) / 100

Formula for B and P are speculated using average of RP or RD increase vs B or P increase per character.

++ Addressing Guests
Guests includes Han Myong (Han-Myeong), Bangu (Bangoo), Diver, Monkasei, Chie, Sophitia!, Hage-Sieg, Nugi Taki, Sophitia!!, Belti (Vercii), and Mabochie. They have different weapon models but all have the same stats as Cervantes. The following is the moveset for each of them:
* **Han Myong:** Hwang's weapon set
* **Bangu:** Seong Mi-na's weapon set
* **Sophitia!:** Sophitia's weapon set
* **Nugi Taki:** Taki's weapon set
* **Hage-Sieg:** Siegfried's weapon set
* **Sophitia!!:** Sophitia's weapon set

Siegfried!'s and Teppou Hei's weapon #1 to #7 often crashes the game and if they work, they only mimic the shape of last weapon you select without the texture.
